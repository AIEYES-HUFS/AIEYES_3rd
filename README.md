**교재:** [파이썬 머신러닝 판다스 데이터분석](https://book.nifos.go.kr/%24/10140/contents/5817510)

### 교재 목차

**PART 1. 판다스 입문**
1. 데이터과학자가 판다스를 배우는 이유
2. 판다스 자료구조 (2-1. 시리즈 / 2-2. 데이터프레임)
3. 인덱스 활용
4. 산술연산 (4-1. 시리즈 연산 / 4-2. 데이터프레임 연산)

**PART 2. 데이터 입출력**
1. 외부 파일 읽어오기 (CSV / Excel / JSON)
2. 웹에서 가져오기 (HTML 표 속성 / 웹 스크래핑)
3. API 활용하여 데이터 수집하기
4. 데이터 저장하기 (CSV / JSON / Excel / 여러 데이터프레임을 하나의 Excel로)

**PART 3. 데이터 살펴보기**
1. 데이터프레임의 구조 (미리보기 / 요약 정보 / 개수 확인)
2. 통계 함수 적용 (평균값 / 중간값 / 최대값 / 최소값 / 표준편차 / 상관계수)
3. 판다스 내장 그래프 도구 활용

**PART 4. 시각화 도구**
1. Matplotlib (선 / 면적 / 막대 / 히스토그램 / 산점도 / 파이 차트 / 박스 플롯)
2. Seaborn 라이브러리
3. Folium 라이브러리 - 지도 활용

**PART 5. 데이터 사전 처리**
1. 누락 데이터 처리
2. 중복 데이터 처리
3. 데이터 표준화 (단위 환산 / 자료형 변환)
4. 범주형(카테고리) 데이터 처리 (구간 분할 / 더미 변수)
5. 정규화
6. 시계열 데이터 (시계열 객체로 변환 / 시계열 데이터 만들기 / 활용)

**PART 6. 데이터프레임의 다양한 응용**
1. 함수 매핑 (개별 원소 / 시리즈 객체 / 데이터프레임 객체)
2. 열 재구성 (열 순서 변경 / 열 분리)
3. 필터링 (불린 인덱싱 / isin() 메소드)
4. 데이터프레임 합치기 (연결 / 병합 / 결합)
5. 그룹 연산 (그룹 객체 만들기 / 그룹 연산 메소드)
6. 멀티 인덱스
7. 피벗

**PART 7. 머신러닝 데이터 분석**
1. 머신러닝 개요 (머신러닝이란? / 지도 학습 vs 비지도 학습 / 머신러닝 프로세스)
2. 회귀분석 (단순회귀 / 다항회귀 / 다중회귀)
3. 분류 (KNN / SVM / Decision Tree)
4. 군집 (k-Means / DBSCAN)
